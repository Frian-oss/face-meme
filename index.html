⚙️ 设置 — Giphy API Key

表情包来自 Giphy 在线搜索，需要一个免费的 API Key：

  1. 打开 Giphy Developers 并登录（支持 Google / GitHub 账号）
  2. 点击 Create an App，产品类型选 API，填个名字（如 meme-radar）
  3. 创建后页面会显示 API Key，复制粘贴到下方

Key 只保存在本浏览器（localStorage），不会上传。
